# React Components Practice

A simple React project built to practice reusable components, props, state, and event handling.

## Features

- Header and Footer components
- Reusable Card component
- Button component
- Form component with `useState`
- Dynamic updates using props and state

## Technologies Used

- React
- JavaScript (ES6+)
- CSS
- Vite

## How to Run

```bash
npm install
npm run dev
```
